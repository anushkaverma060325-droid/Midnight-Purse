# Midnight-Purse
MIDNIGHT PURSE is a dark-themed pocket money management app designed to help users track their income, expenses, and savings effortlessly. It organizes spending into categories like food, travel, shopping, health, and emergencies, with real-time balance updates whenever money is added or spent.
